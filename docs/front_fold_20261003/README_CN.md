# 上楼前腿过度折叠奖励修正

新增 `stair_ascent_front_fold_cost`，只接入 StairTeacher。Actor/critic观测、动作、台阶完成/交替奖励和pre_teacher保持原样。候选软包络的唯一参数源为 `mdp/gait_refinement.py::TUNING`。

## 设计

测量髋关节body原点到轮心的欧氏距离 `L`、膝角绝对值 `Q`；长度对机身俯仰、世界高度和整体旋转不敏感。只处罚越过包络的部分，不要求固定膝角或保持腿伸直。

| 阶段 | 激活条件 | 候选包络 |
| --- | --- | --- |
| 稳定支撑 | 上楼且前进；有效局部地面；接触力有显著向上分量，轮心匹配踏面；连续接触超过缓冲时间 | 更严格，抑制承重时蹲低、缩腿 |
| 摆动抬腿 | 上楼且前进；有效局部地面；接触传感器确认无接触 | 更宽松、成本更小，仅限制极端折叠 |
| 初始触地缓冲 | 已接触但尚未进入稳定支撑 | 本项为零，允许落脚吸收冲击 |

计算为：两个前腿分别取“长度不足的归一化平方”与“膝角过大的归一化平方”的较大者，并截断到有界成本；支撑成本与较弱的摆动成本合并后取两腿平均，乘负权重。参数具体数值以代码台账为准。

上楼门控取完整扫描里的上升边缘，包含机身最近越过但前腿仍在处理的阶；当前活跃上楼目标可跨越暂时扫描变化。前进命令关闭、当前下降任务或episode重置旧目标时退出；纯转向、平地和无效局部地面不生成成本。支撑与摆动门控互斥。

预期顺序：抬腿时可以正常屈膝 → 越阶时避免折叠到极端姿态 → 初触地允许短暂缓冲 → 稳定承重后逐渐伸展 → 对侧腿继续下一阶。原来的逐阶交替事件账本继续决定落脚顺序。

## 实测依据

冻结采样权重：`logs/rsl_rl/deeprobotics_m20_stair_teacher/2026-10-02_00-12-17/model_80100.pt`。副本及改前源码在 `.scratch/front_fold_20261003/baseline/`。每场景5阶、踏面30cm、0.5m/s命令、750控制步；均四轮通过终点且未跌倒，此终点指标没有单独证明无绕行。

| 楼梯 | 稳定承重前腿最短距离 | 全帧最短距离 / 最大膝角 | 近零接触力摆动样本越过极端包络比例 |
| --- | --- | --- | --- |
| 15cm | 0.381m | 0.283m / 2.164rad | 0% |
| 25cm | 0.354m | 0.185m / 2.756rad | 约13.52% |

两场景的稳定承重均未越过新增支撑包络。25cm摆动中观察到了极端折叠，因此增加较宽松摆动包络；不能将全部较深屈膝当作承重姿态故障。以上接触力代理采样没有使用Isaac奖励的完整上楼/扫描门控，不代表训练中的奖励激活比例。数据见 `front_baseline*.json`、`baseline*/swing_summary.json` 与原始NPZ。

## 检查与限制

- 数值检查：正常上楼、正常屈膝摆动、初始触地、平地、下降、零速、反向、纯转向、立面接触和无效扫描均为零；稳定深屈支撑、极端摆动为正；左右镜像和整体旋转一致；扫描过渡与episode reset检查通过。
- 既有交替、同阶、姿态及后腿奖励检查通过；pyflakes无新增告警。
- Isaac Lab的最终代码16环境60步检查载入了新项、正确解析实体，244维actor/285维critic均有限，未执行优化或训练。该短回放没有上楼样本，不能宣称新项在此物理回放中非零激活；非零分支由数值轨迹验证。报告为 `isaac_smoke_final.json`。
- 独立Codex同谱系只读复审；没有异厂模型复审。新包络初值仍需微调结果验证。
- 连续接触缓冲意味着短时间重复卸载可能避开“稳定承重”部分。这是保留正常换步与缓冲的边界；新增摆动部分可约束极端悬空折叠，但仍不能仅凭负奖励降低判断训练成功。
- 未进行新权重训练、真机测试或步态改善验收。新配置需要重新启动训练；修改源文件不会改变启动前已有的训练进程。

## 经验：现象 / 真因 / 判据 / 修法

**现象**：上楼前腿显著折叠。**真因**：通用hipy/knee参考在楼梯附近大幅放松，且阶段相同的屈膝量含义不同；只检测稳定承重会漏掉25cm摆动中的极端折叠。**判据**：按实际接触和轮心与地面匹配分阶段，检查长度及膝角、任务通过和样本量。**修法**：支撑与摆动采用不同软包络，触地保留缓冲；参数只维护在TUNING。
