# 楼梯三项步态修正与续训方案（2026-10-07）

## 结论和范围

最近一版没有白练：冻结的196600 Actor已实际完成原始stairs_ascent.xml的20级登楼。它学到了任务能力，但旧奖励对早期承载深折、摆动深折、延迟同阶落地覆盖不足。建议继承这个已验过的Actor，在新奖励下重建Critic和优化器，保留原权重作为对照。

本次修改仅涉及canonical stair_teacher.py、stair_teacher_env_cfg.py及相关验证脚本。pre_teacher、部署程序、机器人、观测244→16、速度命令、地形生成和升降级未修改。没有启动长期训练，也没有产生新策略权重。实现及数值参数统一保留在stair_teacher.py/TUNING，本文说明取自本次代码，不作为第二份配置。

## 1. 前腿膝角和前机身净空

角度a是膝铰平面内夹角，a=180°−|q_knee|，不是三维关节中心内角。前腿内角越小越深折。保留抬腿跨阶空间，同时从两个独立信号约束：

- `stair_ascent_front_fold_cost`：15cm及较低台阶时，承载偏好a≥90°，摆动偏好a≥80°；从15cm到25cm连续放宽，高端分别为85°和70°。髋到轮心长度同步约束，支撑偏好不少于0.36m、摆动不少于0.30m。这些是软偏好，不是硬限位，也不代表已经找到25cm严格跨两阶的可行最优姿态。
- 取消0.20秒免罚盲区；有效竖直载荷开始时即可启用，以接触力连续调节强度。有效承载需Fz>5N、Fz>合力模长的一半、局部地面有效、轮足高度接近踏面。最初接触有柔和力增益，不强制瞬间伸直。
- 没有有效竖直支撑的前轮采用摆动包络，包括轻擦或立面接触；不能靠擦台阶关闭折叠成本。正常平地、纯转向、倒退和无效局部扫描不启用此登楼项。
- 新前折成本使用x²/(1+x²)有界单调超量函数；严重超量不会突然进入硬截断平台。总体权重由−0.5改为−1.5，摆动不再额外减半。
- `stair_ascent_front_body_clearance_cost`：将前机身下包络9个点按完整姿态转到世界坐标，与附近有效高度采样比较，偏好前腹底垂直间隙≥0.22m，权重−1。采用固定M20碰撞下包络z=−0.07m，不使用base_z−0.5m站高公式。**这是保守包络的高度图净空代理，不是精确几何距离，更不是水平立面距离。** 膝a大与机身离阶远并非等价，因此分别记录。

对原始20级录制的姿态计算假想新成本（固定旧qpos和实际物理接触力，几何在离线副本重构，不运行新策略）：前折加权rate均值约0.718、峰值1.213；前腹净空最小约0.192m，低于22cm偏好的样本约13.4%，净空加权rate均值约0.0041、峰值0.1085。净空项不会把全部登楼姿态都重罚。见recorded_posture_costs.json。这只能核验代价是否作用旧缺陷，不能证明未来PPO一定改善。

## 2. 下楼后腿前倾

保留原`stair_descent_rear_fold_cost`控制腿长和膝折；新增`stair_descent_rear_forward_cost`，使用髋→轮心矢量：

- b：机身坐标系矢量的前向角，相对机身−Z；初始软偏好b≤35°。
- g：仅消除偏航后的重力坐标系前向角，相对重力−Z；初始软偏好g≤25°。
- 高落差从15cm到25cm允许额外放宽最多5°；取两个超量中的较大者，经有界函数再对两条后腿取平均，权重−1。
- 只约束下楼且有有效竖直承载的后腿，允许正常后摆和有限前伸制动。用已锁定下楼目标维持门控，避免前轮到平地、后轮还在台阶时扫描门控提前消失。
- t为大腿相对机身的方向，仍用于解释姿态；本次不把它再加入独立重复成本。b/g加腿长/膝角覆盖整体前倾和深折两类问题。

数值反例中，0.45m长、49°前倾的后腿原折腿成本为0，新前倾成本为正；正常竖直后腿为0。避免把前倾误当成严重折腿。本次固定下楼旧录制上的加权峰值约0.235；它只影响超量帧，不整段压制下楼。

## 3. 前后腿逐阶换侧、禁止延迟同阶

原先front/ rear target首次确认后就退休，而同阶成本只看同时接触。FL1离开后FR1到来可以完全避开成本。现在：

1. 前后轴分别对每个物理阶保存左右腿稳定落地历史，最多64个已登记阶。
2. 第一次已确认落地即时记账；之后即使首腿离开、已经开始下一阶、停顿或转身，历史仍保留。
3. 稳定踏面落地需要竖直支撑、轮心与踏面/半径吻合、越过立面并在下一已记录立面之前，连续至少0.04秒；擦立面、摆动经过和单帧接触不算。
4. 有后续更高台阶证据时才归类为中间踏面；顶部平台允许双腿。更高阶的证据保留在历史，短暂扫描缺失不能抹去。
5. FL1→FR1、HL1→HR1，即使分时接触，也分别触发一次同阶事件。该阶弹跳重踏不重复扣同一事件；前后轴同时违规分别计费。命令仍要求前进时，Actor自行转45°不能关闭历史处罚；纯转向/倒退命令关闭style判定但不清除历史。
6. 同阶事件权重改为−4.5/轴/阶；函数除step_dt，RewardManager再乘dt，积分是单次−4.5，而不是每帧都扣−4.5。现有短时双足同阶停留rate项保留。
7. 正确FL1→FR2→FL3、HL1→HR2→HL3继续获得原完成/顺序奖励；首迈左右均可。同腿连续迈下一阶无完成信用并记现有顺序违规，错误后不永久锁死后续局部学习。
8. 已完成顶部平台、四轮均越过旧立面并站稳，且新阶距离足够远时，允许开始另一段flight；保留历史/预算，释放首迈侧选择。上一段的顶部不会因新段出现而被当成中间阶。

直接跨过未登记阶目前**没有完成奖励，但也没有专门跳阶成本**；不能称作已经全面禁止飞越。严格目标仍是训练偏好，需实际新策略验证，不能仅凭事件曲线断言已经学会。

## 4. TensorBoard

现有Episode_Reward会显示新增净空与后腿前倾项。Curriculum/gait_quality增加：

- `front_loaded_a_mean_deg`、`front_swing_a_mean_deg`
- `front_body_gap_mean_m`、`front_body_gap_low_fraction`
- `rear_body_b_mean_deg`、`rear_gravity_g_mean_deg`、`rear_forward_excess_fraction`

Curriculum/step_completion增加前后轴各自：

- `up_front/rear_unique_tread_fraction`：已记录中间阶是否只出现一只腿；不判断正确侧。
- `up_front/rear_strict_riser_fraction`：已记录中间阶是否正确侧且未同阶跟随。
- `up_front/rear_recorded_intermediate_treads`：分母样本量，防止少量样本被误读。

这些是局部已记录阶指标，**不是整段严格交替成功率**。样本不足时不应单独解读比例。单腿但顺序错误的反例unique=1、strict=.5，证明两者不同。原up_success_rate仍是首次目标落地信用，不能替代严格比例。

## 6. 从哪里继续

推荐196600：已固定真实20级通过和姿态证据，SHA256为765228e6499dd8af9fd3eb7d41d8289072b4478ad20e19ce95b23ab8f7862fe8。目录较新权重199998仍保留，但未做同一套固定评测，因此不自动认为它优于196600。149999可保留作对照：旧测试能耗较低，不能据此判定它更容易学新步态。回到pre会放弃已学到的登楼能力，当前无需这样做。

由于回报定义改变，推荐现有`--init_actor_from`做Actor热启动：包含Actor状态字典中的网络和分布/归一化状态；Critic、优化器、迭代计数重新开始。它属于继承已有策略继续训练，命令上不要同时加`--resume`。传统`--resume`会把旧Critic、Adam和迭代数也恢复，适合同一奖励下续跑，本次不是首选。

在项目根目录执行：

```bash
conda activate m20_wzh
python scripts/reinforcement_learning/rsl_rl/train.py \
  --task Rough-Deeprobotics-M20-StairTeacher-v0 \
  --headless \
  --init_actor_from logs/rsl_rl/deeprobotics_m20_stair_teacher/2026-10-06_22-06-56_stair_resume/model_196600.pt \
  --run_name gait_safety_v2 \
  --max_iterations 5000 \
  agent.algorithm.learning_rate=0.0002 \
  agent.algorithm.schedule=fixed \
  agent.algorithm.clip_param=0.1
```

固定学习率避免adaptive重新把“小起始学习率”调大；clip=.1限制单轮更新幅度，但不是绝对防崩保证。先做5000轮校正预算，原保存间隔100轮，约每500轮固定MuJoCo评测；没有主动启动此命令。热启动计数从0开始，所以不要把model_4999与旧model_196600按文件数字直接比较。

评测保持当前原始20级/20cm踏深和宽踏面30cm登楼、下楼、平地转向四类；起点/速度/成功判据固定，保留旧196600作对照。先判断任务通过是否保持，再看分阶段a的P5/超量比例、前腹净空、后腿b/g超量、每腿第一次稳定落阶序列，以及功/距离与力分位。平均角度和总reward不能替代这些指标。若多次固定测试出现任务能力下降，保留旧模型并回调新成本/边界，不按预设轮数盲目扩训。
