# M20 驻足/停车：观测裁剪与闭环蒸馏验收（2026-10-12）

范围：rl_training 项目原 Quiet Landing V1 的 model_257100，驻足与释放前进命令停车。数值与原始实测分母以项目 `docs/m20_idle_stop_257100_20261012/` 的 criteria、verdict、extra_verdict 和 validation 为唯一台账；本条只记录方法与判据。

## 现象

零命令仍缓慢滚动。受控PPO奖励提高、轮输出变小，原MuJoCo仍有残余运动；只改四个轮输出行的离线拟合也可能让停车原地偏转或让楼梯累计触地能量回退。单看函数级腿输出相同不能判移动闭环没变化。

## 真因

1. 高度观测经过裁剪后，未知/无效原始扫描或全范围外的不平地扫描可变成有限的常数；只核 finite 和极差会把它们误判平地。
2. 策略的 previous_action 和轮速度形成反馈。只拟合原策略采集的输入，新策略产生的状态/动作反馈不在原数据分布中；保留同输入腿函数不等于保留闭环腿轨迹。
3. 停车后命令为零不证明停车前真的在运动；驻足只核终点净位移会放过先走出去再回来的轨迹。
4. 记录表里写了checkpoint名/“无外部修正”不等于身份已经核实。冻结哈希必须接实际模型、策略、地形XML与加载器，以及当前部署源；不要漏掉停车真正使用的平地XML。
5. 原checkpoint可能带更早的 preservation_reference_actor。完整resume可能继续锚定旧基准；必须显式选本轮参照actor并逐张量确认。校准模型后续训练使用 actor-only初始化，不能把沿用的critic/reference当作新训练已验收。

## 判据

- 必须执行原部署物理路径，只替换窗绘、输入源和墙钟等待；分别核动作/命令的物理前时戳与完整状态的物理后时戳。
- 从冻结台账核全部命令和模式时序、完整时长、实际停车前运动、最大位置偏移、末段路径长度/时间、驻足和停车偏航；禁止用来回运动相抵的净位移替代最大偏移。
- 对移动楼梯保留检查同时用触地窗口力峰值、累计轮心平动比能量/前进距离、事件数、到达时间与跌倒；只报单事件均值会漏掉事件次数增加。
- 身份/SHA变更、无运动命令、停车前未动、往返、偏航异常、跌倒与无触地样本必须实跑反例变红。掩码同时测试真实合法驻足与裁剪后的未知/饱和反例。
- 原始实际观测需逐帧对应command、previous_action、joint_velocity、checkpoint重新推理结果。CPU复现要逐张量匹配actor；函数测试或拟合误差不等于物理行为通过。

## 修法与实测边界

将停止目标限定为训练时已知平地、请求零命令；不以实际速度/接触为门控，从而滚动/抬轮不能逃掉停止目标。实际已知平地扫描也要拒绝裁剪饱和值。收集原策略及失败候选的真实反馈观测，增加向零收敛的previous wheel action/velocity监督输入；对移动与腿输出蒸馏原基准。监督augmentation是函数训练样本，不能包装为物理实验。

本次最终用原MLP末两层监督蒸馏，前两层与std冻结，保持原actor格式，未加运行时裁剪/控制器。固定驻足、释放W停车、楼梯保留三例通过；低速、倒车、转弯后的停车补充检查通过。横移停车偏航仍未过额外严格线，已留在extra_verdict中，不宣称所有命令/全地形/真机全绿。原模型未覆盖。拟合工具为项目 `scripts/tools/finetune_idle_stop_wheels.py`，训练掩码为 `source/rl_training/m20_quiet/idle_stop.py`，实际调用接线已用CPU重现。

跨机器仍会重犯，故保留为方法条目。独立复核实际family为Codex，异构缺档如实记录。
