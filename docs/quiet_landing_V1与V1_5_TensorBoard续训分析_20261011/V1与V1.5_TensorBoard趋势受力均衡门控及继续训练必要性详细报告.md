# V1与V1.5 TensorBoard续训必要性分析

## 读取范围

- V1：迭代 214700—256829，104 个标量指标；文件冻结读取字节数与SHA见日志冻结来源.json。
- V1.5：迭代 214700—234414，117 个标量指标；文件冻结读取字节数与SHA见日志冻结来源.json。

## 结论

V1后期收益很小，继续原样长训优先级低。V1.5仍有缓慢改善，不能判定已经收敛；但改善没有稳定迁移到此前MuJoCo全地形回放，且受力均衡项虽然触发，覆盖与贡献很低。应优先验证/改善有效支撑样本覆盖和评测对齐，再决定是否续训。

## 受力均衡项：已触发但有效样本少

- 最近1000更新稳定支撑时间比例日志均值 0.08599%（约每1000秒采样时间0.860秒满足完整稳定门控；这是日志批次比例的均值，不是重新汇总的全局时长比）。
- stable_has_samples均值为35.23%，它描述重置批次是否有稳定样本，与有效时间比例不是一个量。
- 稳定支撑对角差绝对值均值 0.16890，奖励死区0.05；早期窗口为0.18167，近期两个5000更新窗口只变化约-0.56%。
- 均衡惩罚贡献约-0.0000228 reward/s，冲击峰值约-0.316640、触地约-0.688798；均衡项分别约为它们的0.00721%和0.00331%。平均贡献不能直接等同于策略梯度，但说明信号量级很小。
- 门控要求全扫描高差≤0.025m、四轮连续支撑≥0.15s、四轮法向力>5N、总力≥100N、低垂向速度和低机身角速度、朝向命令较小及机身接近水平。代码上这些条件可能减少迈步时覆盖；现有日志没有逐条件拒绝率，不能判断哪个条件主导。
- V1没有QuietLoad日志，缺失不能解释为零力或零稳定样本；MuJoCo采样器未传balance_gate，与训练门控不同。

## 优化与任务保留

- 学习率固定1e-5、critic warmup已结束，loss/value有限；日志未显示数值发散，但未记录KL和clip fraction，不能据此证明PPO更新始终理想。
- 动作标准差持续下降（entropy_coef=0），探索正在减弱；不能凭标准差下降单独判定收敛。锚定损失较早期增大，表示相对baseline发生漂移，不能直接判断漂移好坏。
- 回合长度接近1000步上限，表明训练中多数回合持续较久；不等于楼梯通过率。平移跟踪误差较早期有所增加，需关注任务与quiet取舍。
- Episode_Termination来自本机TerminationManager中各环境最近一次终止原因的存储状态；约98.7%的time_out不是严格的本窗口新回合成功率，更不是上/下楼成功率。

## 为什么与MuJoCo有不同结果

- TensorBoard统计随机命令、多地形课程及训练动作采样；此前MuJoCo使用确定性Actor和单一all_terrain路线反馈。训练物理指标改善不能直接推导固定下楼场景改善。
- 所有训练quiet统计都包含失败回合；冲击峰指标是重置批次内回合最大值，再经过日志平均，不是无跌倒单次触地力峰均值。二者不能直接比较绝对值。
- TensorBoard未保留楼梯方向、地形等级/类型、命令暴露、逐门控拒绝率的分组日志；课程可能改变采样难度。现有日志无法将quiet变化与采样难度变化完全分离。
- V1.5峰值惩罚使用不饱和尾部公式，V1使用饱和公式；V1.5峰值reward更负不等于力更大，总奖励跨版本也不可直接排名。
- 日志以重置批次汇总，再对每更新中的batch取均值；本报告均值是TensorBoard标量的窗口均值，未伪装成逐事件加权总体统计。

## 建议

- V1：优先暂停原样长训并保留230300/237200/255900候选；收益已很小且下楼闭环有退步。这里是建议，本轮没有停止训练。
- V1.5：不应仅因最新一次MuJoCo退步就认定无训练价值；训练累计动能仍缓慢降低。应先增加门控条件覆盖诊断，确认受力均衡项能得到足够有效样本，再做有限续训及固定场景复测。
- 继续训练的验收应同时看下楼力峰P95/最大值、每米累计比动能、任务完成与速度跟踪、稳定支撑对角差；不以总奖励或迭代编号单独选模型。
- 本轮只读取日志并生成分析，未修改奖励、观测、配置或运行中的训练。
