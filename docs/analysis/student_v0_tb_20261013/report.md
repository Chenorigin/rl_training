## 日志口径与不能推出的结论

1. 近期教师实际执行时间步比例平均 0.50282。奖励、跟踪、终止、落地指标都是教师和学生混合控制结果，不能作为学生独立通过率。
2. 姿态异常终止记录近期均值为 0.001973。当前安装的 TerminationManager 对全部环境最近一次终止状态取均值；它不是本窗口真实失败 episode 数除以总 episode 数。不能将该数字直接称为 0.197% 的学生跌倒率。
3. 速度误差由 CommandManager 按命令最大持续步数归一化并累加；这里沿用日志口径，不把它解释成重新计算的逐帧 RMSE。
4. 落地 P95 是各重置组的直方图估计经 logger 汇总的结果，不是全窗口全部落地事件重新计算的全局 P95。峰值力也是重置组最大值的日志汇总。
5. QuietLanding/all/has_samples 近期平均 0.99459，落地指标有样本支持。QuietLanding/all/map_valid_fraction 一直为 1，它来自落地诊断的原始扫描，不是学生输入的有效性通道统计。
6. QuietLanding/distance_m 和 touchdown_count 在重置组内求和，早晚重置组大小变化会影响数值；其下降不能直接解释成机器人不再前进或不再落地。
7. 全部感知强度保持 0.25；没有 Perception/、Eval/ 或按地形难度分层的指标。现有日志不能回答置信度是否被正确利用、位姿错位鲁棒性如何、是否保留教师高档楼梯能力。
8. 32 个选取指标没有 NaN/Inf。三项动作损失的步号完整对齐，满足整体 = 0.75×腿部 + 0.25×轮部（浮点相对容差 5e-6）。未检查未选取指标、模型参数或真实执行轨迹。

## 建议

保存现有模型作为轻度退化基线。优先补充学生独立闭环评估，以及按地图缺失、延迟、位置/航向偏差分组的样本量、动作误差和任务完成情况，再决定提高退化强度或继续同一阶段。异常尖峰需要记录教师/学生动作幅值和最差样本来源来定位。当前约 0.01 的训练 MSE 不能作为可上真机的验收阈值。

本次未执行学生独立仿真、真机测试或新的对照训练；这些能力结论保持未验证。
