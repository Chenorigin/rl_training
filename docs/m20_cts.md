## v20：上行中途暂停原位保持

唯一数值入口为 `all_terrain.stair_stop`；缺少该节或 `enabled=false` 保留原行为。
只作用于上楼和往返上行的中途暂停，初始等待、顶部终点停车、下楼和平地任务不变。
最后一个前进物理步结束时锁定机体位置、四轮中心平均位置和航向；进入帧不领取停车奖励。
前移制动余量由实测世界前进速度计算，并受上限和当前踏面深度限制；后退、侧移容差独立。
锚点在整个暂停中保持不变，不能靠滑退后重置位置获得完成。

实际零命令物理步内，替换原有宽尺度速度/偏航跟踪及停车奖励，加入位置、承重轮接触点滑移、
有界支撑覆盖和姿态角速度代价。后轮滑移权重高于前轮；不奖励接触力大小，不锁默认关节姿态。
恢复要求在停车区域内、航向及速度合格、前后都有有效支撑、接触滑移合格，并满足原连续停稳时间。
允许两轮或三轮调整支撑，不要求四轮同一踏面；超出停车区域不会立即终止，仍可修正，但不能算停稳。
重启判定帧仍按实际执行的零命令评分，下一前进物理步解除位置约束；保留原暂停超时和后轮停滞规则。

`CTSAllTerrain/stair_stop/{teacher|student}/{up|roundtrip}/...` 分别记录进入、恢复、耗时、
停车帧、区域外帧、有效支撑、接触滑移、完成回合最大后退、恢复后通关、持续前进与触发前失败。
指标随checkpoint保存；resume重启物理历史，不把半途回合算成完成。均值必须使用对应完成/恢复计数，
不能把累计事件比值当独立测试集成功率。新增奖励收益须由后续训练和同条件回放验证。
验证记录：`logs/evaluation/cts_v20_stair_stop_20261031/`。

## v18：外围地图质量与楼梯起步静止

本次针对 `cts1000_wall_diagnosis_20261030/REPORT.md` 的复现实验修改训练。
同一物理场景只改变外围地图有效位/置信度即可触发退后，因此补齐这条输入变化的监督。
唯一数值台账为 `cts.json` 的 `all_terrain.wall_stability`。

- 外围已知格做稀疏缺测、单侧缺测或仅置信度衰减；失效时高度、有效位、置信度一起清零。
  原未知格不补成平地，中央踏面、历史、机器人状态和指令不变。使用实际平坦支撑及教师中央地形
  检查，排除台阶跨越、坑、坡、失支撑和恢复阶段。学生向安全且停止梯度的干净视图对齐；
  腿动作一致性覆盖合格状态，轮速一致性只作用于原始零指令。
- 为共享解码器增加独立 `idle_wheel_mlp`，仅原始零指令启用。输出为四轮各自的可学习增益，
  初始严格等于 1，旧权重迁移不改变动作；非零指令使用原路径。该分支通过 PPO 训练，
  学生另受静止输出损失监督。增益不能翻转轮速方向，不把它描述成完整恢复控制器。
- 楼梯入口延长静止等待，同步延长回合超时并对齐恢复课程计时。已有实际轮速、腿速和动作变化
  代价覆盖楼梯的水平支撑区；正常运动、跨阶及坡面不加此静止约束。硬零输出辅助还要求低实测速度；
  实际速度惩罚不因后退加速而消失。

`CTS/ppo_wall_idle_*` 与学生的 `wall_idle_*` 分开记录；`wall_quality_*` 记录有效样本、
三类扰动和腿/轮一致性误差。监督样本数为零时不能把损失为零解释成学会。
不改变部署感知过滤、物理墙碰撞、heading latch、软件关节限位、PD 或地形课程配比。
这是训练修复；必须用新训练权重复跑墙边、楼梯和移动指令矩阵后，才能判断行为改善。

## v17 的修改（继承）

唯一数值台账为 [cts.json](../configs/distillation/cts.json)。本版针对实机 v15/7000 的
滑后偏航、附近物体引发大腿动作、软件越限和依赖助跑四类问题修改训练，尚未证明新策略收益。

- `all_terrain.stair_recovery`：上行及往返课程混合近阶静止起步和普通助跑起步；前三阶随机设置一次暂停，必须实际爬到位置、停稳后再发前进。出生保持在首阶前，不把默认姿势瞬移到阶上。速度由该节 `speed_m_s` 独立采样；纯下行仍用 `commands.forward_speed`。暂停超时、持续前进但后轮无有效进展均失败；中途暂停不能计成路线完成。
- 偏航奖励使用动作产生时该 cohort 实际收到的 yaw 命令，避免原始零转向目标抵消已有纠偏反馈。额外约束路线朝向和横向偏离，训练中加入有界横向/偏航速度扰动。没有修改部署端 heading latch，也没有假称左右轮摩擦已独立随机化。
- `all_terrain.obstacle_response`：在原物理墙课程中补短墙、立柱，左右侧独立抽样，物理 mesh 与高度图保留同一障碍；加强平地墙边腿动作变化和抖动代价。实体静态，机器人经过产生视野变化；本版未加入动态行人仿真，不能据此声称已验证行人场景。
- `all_terrain.safety_learning`：在现有软件余量约束上增加完整教师/学生动作的尾部越限代价，作用到原始动作映射，极大输出也保留向内梯度。统一拒绝不安全的参考、蒸馏、时序双端、直行和旧能力标签；被拒状态仍接受学生直接安全代价。拒绝标签在平方前处理，避免 NaN 梯度。禁止把裁剪后合法当成原输出合法。

继承 v16 的教师全网络更新：基础 MLP、残差、安全和静止网络使用独立
`algorithm.teacher_learning_rate`；解码器/critic 与学生分别使用各自已有学习率。
`reference_teacher` 和探索噪声仍冻结。没有放宽 SDK/训练软件限位或修改 PD 增益。

`CTSRecovery/*` 记录近阶起步、暂停、成功恢复前进、停不稳失败、后轮停滞失败和扰动计数；
`CTS/teacher_limit_tail_loss`、`reference_rejected_fraction`、`unsafe_teacher_fraction` 及
`retention_rejected_fraction` 用于检查安全目标与标签覆盖。完成判定仍要求全轮通过终点并停稳。
观测/输出 ABI 保持 sensor789＋raw command3→nominal16。

## 楼梯周边墙体混合

`all_terrain.stair_walls` 为上楼、下楼和往返楼梯加入无墙、左侧墙、右侧墙、双侧墙。
各几何等级的样本池均衡分配布局，原楼梯尺寸、摩擦材料、出生点和终点保持原随机路径。
墙高、墙与楼梯边缘间距、墙厚以 JSON 为唯一数值台账；侧墙延伸至起步区和终点平台。

墙体同时进入真实碰撞 mesh 和感知射线；用于后腿过阶、支撑和安全标签的踏面查询排除墙顶，
避免把墙顶当成可落脚台阶。全身碰撞包络检查墙距、侵入失败和近墙代价，
不在楼梯套用平地墙边的抬腿／腿速惩罚。近阶静止起步、前三阶暂停再启动和偏航扰动继续生效。
按教师／学生、楼梯类型、墙布局分别记录 frames、episodes、successes 和 wall_failures，
零覆盖单元也输出；汇总成功率不能替代各布局检查。

使用下述 `--init-cts` 命令创建新 run 才会采用新增配置；旧保存配置缺少该节时保持旧行为，
`--resume` 不会自动升级。证据在 `logs/evaluation/cts_stair_walls_20261030/`。
这是墙体布局训练覆盖，未包含动态行人，也未证明新策略的实机收益。

## 后腿抓地与过阶奖励复审

新增可选 `all_terrain.hind_ascent`，默认启用；参数以 JSON 为准。保留原后轮净空不足、
顶阶接触代理、双后腿失支撑成本和全轮滑移项。顶阶项使用净反向力，不能当作逐接触点标签。

- `hind_stable_step`：左右后轮分别记录实际上升踏面；完整后缘越沿、轮底/支撑高度吻合，
  并在低滑移下连续支撑后，单阶只给一次奖励。确认时间按踏面可用长度和速度缩短，
  保留最少连续样本要求，避免窄踏面高速滚动被迫停顿。出生已在阶上、跨越未落脚的中间阶、墙顶、
  原地重复抬落和后退重上均不能刷取事件。全路线正奖励有固定预算。
- `hind_supported_progress`：同一后轮在有效上升踏面支撑时取得的新进展才给分；
  悬空、滑动、暂停阶段已经取得的位移不留到落脚后补领。进度高水位不随后退降低，预算有界。
- `hind_ascent_slip`：仅上行前进时的后轮有效踏面接触增加带死区、有上限的滑移成本；
  在原全轮成本之上追加，日志分别记录。接触材料点速度含轮子转动，正常纯滚动不罚。
  这是踏面支撑滑移代理，不宣称测出了棱边/立面的逐接触点滑移。
- 修复原停滞判断中“悬空后腿前摆借另一后腿支撑”误清计时；改为左右后轮各自确认的支撑位置。
  修复踏面高度与出生高度混用；非有限原始轮位姿/接触速度/力拒绝正奖励并在上行终止。
- 原抬轮、冲击、能耗和软件限位继续约束动作，不新增大力矩/大接触力正奖励，也未启用无依据的承重区间。
  分教师/学生、左右后轮记录过阶次数、各项积分、支撑时间、滑移距离及法向力冲量，后者只用于诊断。

事件和位移奖励显式消除 RewardManager 的 dt 缩放；状态在每个控制步物理推进后记账一次，
多次读取奖励不重复计数。部分复位清除对应历史，恢复保留汇总计数并重启回合。
使用 `--init-cts` 新 run 采用新目标，正在运行的旧进程不会热更新。
验证记录：`logs/evaluation/cts_hind_ascent_20261030/`；新训练收益和实机改善仍待验收。

## 复合指令与逐轴跟踪

默认配置 `all_terrain.compound_commands.enabled=true`。一般运动地形（motion、rough、blocks、pits、mixed）由 11 模式扩为 19 模式：保留原单轴/空闲模式，补齐前后走＋左右侧移、左右侧移＋左右转向，覆盖 WASDQE 的全部 12 个非相消两键组合。相消命令仍是零目标，不单设奖励。

新增节的速度区间覆盖当前键盘全幅：前后速度上限 0.7 m/s、侧移 0.5 m/s、转向 0.6 rad/s。前后走转向取消原来的半幅转速。每个分量分别采样，含小分量、半幅和全幅附近；所有数值以 `configs/distillation/cts.json` 为准。原楼梯、专门直行和平台课程沿用其速度与停止语义。

复合模式混合固定双轴与“单轴→双轴→单轴”的加减指令；先给哪一轴每回合独立随机，与左右符号无关。沿用平滑/突变抽样。组合持续时间按平面速度和配置的保守行程计算，并预留整机旋转足迹和边界余量；移动后重新查询实际地形支撑高度。限制的是采样路径，不裁剪策略输出，也不放宽限位失败条件。

跟踪目标对各轴计算 `(实际速度-指令)/sigma`，激活轴的 sigma 为相对容差乘指令幅度与原绝对下限的较大者；未激活轴保留旧的零目标漂移方差。取最大归一化平方误差后做 `exp(-error)`，同时作用于原 linear/yaw 两个奖励预算，权重总额不增加。这样不能靠某一轴跟得好掩盖另一轴完全不跟。零指令和楼梯/直行/平台使用原目标；姿态、限位、地图扰动、后腿上阶项继续生效。

课程成功判定也逐轴检查 RMS，容差使用实际斜坡及加减轴序列的指令 RMS、已有相对容差/绝对上下限；未激活轴沿用原绝对上限。各模式记录 `vx/vy/wz_tracking_rms`，避免低幅侧移被总平面误差掩盖。

对照时将整个新增节保留并设置 `enabled=false`，或读取不含该节的旧保存配置，恢复原 11 模式、奖励和随机数路径。加入新目标应使用 `--init-cts` 开新 run；旧 run 的完整 `--resume` 不会自动升级。软件接线和有界零更新验证不能证明新策略收益；需要新训练权重再跑组合矩阵、楼梯和实机验收。证据在 `logs/evaluation/cts_v15_compound_20261029/`。

## 软件关节限位

唯一数值配置为 [cts.json](../configs/distillation/cts.json) 的 `joint_limits`。
按关节名对齐 SDK 修正坐标下的目标角/反馈角边界、默认角和 action scale；
轮关节使用速度控制，不套腿部位置限位。感知与地图参数不因本次限位修改而改变。

训练在发出的 nominal target、每个物理子步的落脚修正目标与反馈位置上检查限位。
越限锁存至该回合重置，执行器在延迟队列之后覆盖为阻尼输出，回合按失败终止；
与超时同时发生也按真实终止处理。接近边界的余量代价覆盖楼梯和非楼梯；
学生蒸馏对完整输出目标加入可微代价，梯度通过冻结的共享解码器传回学生。
相关统计写入 `CTSJointLimits/*`，终止帧的日志在自动 reset 后仍保留。
原非楼梯旧关节余量项在新监控生效时停用，避免重复惩罚。

CTS MuJoCo 的 headless 和 viewer 都启用相同位置检查，含动作延迟之前的发出目标。
viewer 的趴卧、起立、躺下与阻尼阶段仅更新接触反馈；策略接管前检查反馈位置，
接管后每个物理子步执行限位检查。手动启动姿态不触发策略执行器的门控。
启动核验 XML 物理范围与软件反馈边界。首个越限立即失败；有 `--output` 时
另写 `.limit_failure.json`，保存阶段、关节、目标/反馈值与边界。
旧 v14 checkpoint 播放时也使用当前限位契约，因此可能暴露过去静默通过的动作。
不裁剪关节目标来掩盖越限。当前 SDK 的限位和软急停保持原配置。

## 地图过期与稀疏恢复训练

唯一数值配置为 [cts.json](../configs/distillation/cts.json) 的 `map_recovery`。
新 run 默认启用；每回合独立抽取是否加入扰动，覆盖全地形中的教师/学生环境，
不依赖地形类别或指令方向。被选中的回合在随机间隔后暂停有效采集，持续时间
超过当前地图 TTL，然后以少量新格恢复；恢复阶段随机采用保持稀疏后整体恢复，
或逐渐增加采集覆盖率。未选中的回合继续使用原感知扰动。

扰动发生在采集端：旧格保留原时间戳并自然过期，新格继续经过原包延迟、
高度噪声与质量/年龄置信度计算。没有延长 TTL、凭空提高有效性/置信度或插值
策略输入。稀疏化前先按完整地形计算遮挡，避免删除遮挡物后错误看见其背面。
这只是已有高度图传感器代理的时序扩展，不是实机 LiDAR/mapper 的完整复刻。

输入仍为原来的 789 维；关节限位失败判据与损失权重保持不变。此次没有增加
动作平滑损失、墙壁分类/障碍距离通道，也没有修改 MuJoCo 或 SDK 的运行逻辑。
已有权重不会因源码变更获得恢复能力；默认扰动范围是初始训练覆盖设置，
不是已经验证的最优参数，收益和楼梯能力保留仍需新训练后的对照评测。

`CTSMapRecovery/*` 记录选中比例、当前断流/恢复比例、全空比例、新有效格比例、
事件累计数及空图到有效图的转换累计数。最后一项也包含启动首次出图，不能单独
当作“成功恢复”；须结合事件数和回合结果解读。零更新验证报告也保存此统计。
资源预检将额外采集/遮挡工作区单列为 `map_recovery_reserve_bytes`。

可通过 `--config` 指定 `{"map_recovery":{"enabled":false}}` 做对照；关闭时观测、
原队列和随机数状态与旧实现一致。添加此功能前保存的 v15 checkpoint 仍可加载
部署；要采用新训练设置必须使用 `--init-cts`。即使版本同为 v15，旧源码的
checkpoint 也不能绕过源码哈希检查直接 `--resume`。

## 后腿上阶余量奖励

唯一数值台账为 [cts.json](../configs/distillation/cts.json) 的
`all_terrain.hind_clearance`；新 run 默认启用。`configure_all_terrain` 将以下三项
直接注册到原 RewardManager，教师和学生环境都执行同一物理目标；CTS 的教师 PPO
与原学生蒸馏路径保持原算法。TensorBoard 的 `Episode_Reward/hind_*` 显示各项
独立的回合平均贡献，不能把较高奖励当作已经改善上楼成功率。

- `hind_step_clearance`：依据真实碰撞地形的每个上升阶沿，计算轮子完整包络底面。
  在轮子前缘接近阶沿之前平滑提高目标，要求在越沿前达到踏面高度加余量。
  代价为有界的归一化欠高平方；贴地顶阶也计入，不允许用“不进入摆动”逃避。
- `hind_riser_contact`：在阶沿附近、轮子仍低于踏面时，惩罚反向纵向接触力。
  这是结合几何的顶阶力代理，净力不能精确区分每个接触点，不称为踢面碰撞标签。
- `hind_support_transfer`：后轮正在处理上升阶沿时，惩罚两只后轮同时失去有效支撑。
  单后腿抬起、另一后腿承重不会产生此代价；不指定对角相位或固定关节角。

目标只用于前进上阶，包括完整往返路线的上行段；平地、下阶、停车和后退不加这三项。
一只轮子在当前踏面落稳后，该阶沿从候选中排除，下一阶仍会被查询，短踏面不会因为
当前阶沿仍与轮子重叠而晚抬脚。尚未越过的阶沿则保留至完整包络越过，防止中心越沿后
目标过早切换。高于目标不再增加收益，原能耗、动作变化、冲击和软件关节限位仍生效。
目标使用训练特权几何，不把真实地形泄漏到学生输入或部署端。

部署模型的轮子为 cylinder，训练轮子为 capsule。测量工具分别报告真实 cylinder
包络和训练 capsule 包络，使用每个物理子步的独立运动学副本与真实接触求解结果。
“轮子最低点在首次前缘越沿时低于顶面”说明提前净空不足，但不直接证明发生碰撞：
圆轮可能沿阶沿滚上去。也不能据此认定电机力矩不足；实机仍需目标/反馈、执行器和接触记录。

可重复有界诊断（不更新权重，软件越限立即停止并保留此前样本）：

```bash
python scripts/tools/evaluate_cts_stair_clearance.py \
  --checkpoint logs/rsl_rl/deeprobotics_m20_cts/2026-10-29_13-52-43_651779_cts_motion_stability_v14/model_1500.pt \
  --model /absolute/path/to/M20.xml \
  --output logs/evaluation/cts_clearance_new_case --steps 1200
```

输出 `clearance.json`、`wheel_telemetry.npz`；`wheels` 为物理 cylinder，
`training_capsule_wheels` 为训练包络。`effective_contact_friction` 是接触解算实际值，
不能仅用地形 XML 的 friction 推断。已有分析与验收收据在
`logs/evaluation/cts_v15_hind_clearance_20261029/`。本轮只验证奖励接线和旧权重的现象，
未进行长期训练，未验证新奖励带来的仿真或实机改善。

已有 v15 checkpoint 不含此节时仍可部署。采用新奖励须使用上面的 `--init-cts`
创建新 run，不能用旧源码的 `--resume`；源码哈希门保留，既有训练进程不热加载。
对照可用 `--config` 覆盖整个 `all_terrain.hind_clearance` 字典并设置 `enabled=false`，
其余字段保持数值台账原值。当前 CLI 在顶层节内更新，不做更深层字段的递归合并。

综合运动及新增地形覆盖前进、后退、左/右原地转向、前进左/右转弯、
后退左/右转弯、左右横移及零命令停站。左右分别抽样并使用独立课程账本。
弧线样本同时保留固定命令和“直行→原向转弯→反向转弯→直行”序列；
命令变化混合渐变与瞬变。回合包含等待、运动与停车阶段。

## 连续采样与实际地形

楼梯高度覆盖 15–25 cm，踏面深度覆盖 15–35 cm。初始等级从已有能力范围
继续训练，后续依次扩展高度、较短踏面、较长梯段及较窄通道。
初始等级仍是楼梯训练，不加入低矮台阶的重新入门阶段。

地形库在 run 开始时，以保存的种子在连续区间内分层采样：当前为
10 类地形 × 7 个几何等级 × 每级 16 个样本，共 1120 个真实地块。
高度、深度、宽度、障碍尺寸和位置等采用连续取值；台阶数量和地形类别
属于离散结构。每个地块建成后保持静态，回合重置时选择相应等级内已有的
真实地块，不声称碰撞网格会每回合重新生成。
各等级在真实难度轴上连续分层，保证至少五分之一的样本进入难度边界区间；
坡面和波浪分别保证覆盖，避免冻结样本池缺少难例而永远无法满足晋级条件。

碰撞网格、射线、支撑高度/法线、出生点、边界和终点使用同一份几何。
凹陷没有被全局地面覆盖；完整往返楼梯留有平台和落地区域。
独立平台使用覆盖出生位置的抬高台面，避免把高台课程误建成单级高墙。

接触刚度、阻尼随地块在启动时连续采样；摩擦系数、动静摩擦比、质量/惯量
缩放、质心偏移和 PD 缩放在每回合重置时连续采样并作用到该环境的机器人。
材料通过物理接口直接赋值并回读，避免从几个预设材料桶中选择。
物理随机化同时影响教师和学生；DR 等级控制物理采样范围的扩展，感知的
噪声与延迟混合按保存的感知配置执行。
物理碰撞保留每地块单材质网格，使用显式碰撞分组保持环境隔离。
本任务关闭物理复制，以避免 env-ID 共享地形的全空间包围盒放大碰撞开销。
验收同时检查实际碰撞材质、射线高度和两群体的轮地接触力/净空支撑。

## 学生表现驱动的升降级

调度器按“地形类别 × 命令组”维护账本。命令组分为前进、后退（含后退弧线）、
原地转向、前进弧线、停站、左横移和右横移；楼梯与直行专项只使用其对应组。
教师和学生共享该组的几何/物理难度分布，教师成绩仅用于诊断。

只有当前版本、当前难度角色的已结束学生回合参与门控。
回合携带开始时的角色与版本，结束后只结算一次；旧版本、回放和挑战的成绩
不能帮助当前等级晋级或触发其降级。

| 条件 | 调度行为 |
| --- | --- |
| 连续两个互不重叠的窗口，每窗 100 个有效学生回合，成功率均不低于 90% | 晋升一个难度轴 |
| 每个晋级窗口同时覆盖至少 10 个难度边界回合、30 个延迟地图回合 | 才允许使用上述成功窗口晋级 |
| 连续两个有效窗口，成功率均低于 70% | 回退最近增加的一个难度轴；不要求覆盖条件 |
| 中间成功率、覆盖不足或样本不足 | 保持等级；完整中间窗口打断连续晋降证据 |
| 已到最高或最低等级 | 保持边界，不产生空等级或越出几何范围 |

几何与物理 DR 交替逐轴推进；一个轴达到上限后继续推进另一个轴。
回退恢复最近一次变化之前的等级，保持其他轴不变。
每次实际晋降更新版本并清空当前统计窗口，下一次重置才应用新分布。

`curriculum.max_window_updates` 当前为 30000 次策略更新。原因是占比仅 2%
的地形再按命令组划分后，较长回合与当前角色采样共同降低有效样本到达速度；
原 1000 次更新期限可能在凑齐一个窗口前就反复清空它。
本次延长的是证据的有效期，没有降低每窗回合数、成功率或覆盖门槛。
超期证据仍会清除，保存/恢复同时保存窗口、版本、等级历史及采样 RNG。

当前等级、历史已掌握等级、相邻挑战等级的目标采样比例为 60%/25%/15%。
刚开始没有回放池时，对应份额回流当前等级；达到最高等级后，空挑战池也
回流当前等级。回放只从有效历史等级取样，挑战只推进一个轴，三种角色的
证据通过回合角色标签隔离，回放与挑战不进入当前等级统计窗口。

楼梯成功要求四个轮足完整通过终点并完成稳定停车；未走完超时属于失败。
其他运动使用真实速度/转向跟踪和停稳条件，不能仅凭存活判成功。
低速命令采用相对跟踪阈值，避免“不动也算后退成功”。
平台按台缘风险、实际支撑和跨下/停稳分别判定，不套用普通地面的直行终点。

## 教师、学生与平地抬腿约束

v13 的教师动作输入契约使用干净的本体、地形和航向反馈；共享解码器的
教师公共输入也取干净教师观测。学生仍读取含噪声、缺测和延迟的感知输入。
教师与学生经历同样的物理随机化；“干净教师”不意味着机器人或执行器没有扰动。

学生额外地图投递延迟按回合独立选择：20% 为零额外延迟，80% 在保存的
延迟区间内连续抽取秒数，再安排到不早于请求时间的控制步交付。
这与 clean/regular/stress 噪声分组独立。零额外延迟仍有地图刷新周期、
抖动、缺测和其他感知误差，不能当作每个控制步都有无噪声新地图。
关闭新连续延迟开关的历史配置保留原整数步采样和随机数行为。

采集网格保留扩展支持域，最终模型仍接收原来的 187 点前视高程、有效位和
置信度。后方未知区域保持未知；复杂地形后退使用独立成绩与难度，不能把
教师额外可见的后方真值当作学生已经拥有的输入。

平地持续直行专项只在学生专项运动帧上增加解码后 12 个腿动作的蒸馏约束。
目标来自同一实际身体状态下的当前干净教师；车轮动作误差仅监控。
专项不会给楼梯或粗糙地面施加“必须贴地”的动作标签。
真实平地直行的离地/失撑代价也按地形和命令限定，保留复杂地形所需抬腿。

新零命令分支允许受限的腿部姿态修正；新增分支不输出轮动作修正。
教师基座仍冻结，教师残差、共享解码器与 critic 通过 PPO 更新，随后学生
编码器使用当前教师和辅助目标蒸馏。原教师在线动作约束在新地形上按配置
减弱；时序、空间及非前进保留目标继续使用各自的保存契约。

保留数据与原始命令收据位于
`deploy/models/cts/nonforward_retention_startup_20261027/`，属于运行输入，
不随文档清理。启动和恢复检查数据与配置；部署只依赖 checkpoint 内嵌契约。

## 观察训练与验收

TensorBoard 的 `CTSAllTerrain/*` 记录按教师/学生和地形划分的帧数、回合与
成功率，以及每个命令组的几何等级、DR 等级、版本和窗口状态。
`CTSAllTerrain/{teacher,student}/{course}/command/{mode}/*` 记录各命令的
帧数、完成回合、成功、速度误差、身体/轮组位移和失败原因。`CTSStability/*`
记录当前帧代价，不能把它当回合成功率。
`CTS/online_*_course_*_fraction` 用于检查实际优化批次的地形覆盖。
平地专项同时查看 `CTS/straight_leg_action_mse`、左前腿动作误差和

## 墙旁通行与门框转角

新增训练目标位于 `configs/distillation/cts.json` 的 `all_terrain.wall_practice`，默认启用。单墙、双侧通道、门框、前墙停车、左右转角均为真实碰撞墙体和平地；每类按净宽设课程，并随机出生横偏/小偏航。墙课程占 motion 课程中的一部分，保留无墙运动、全部楼梯、崎岖地面和平台任务。分配比例、宽度、速度、间距和代价参数以 JSON 为唯一数值台账。

### 平地高回波抗干扰与前腿下楼参与（2026-10-30）

同一 CTS 学生策略，789 维观测、16 维动作和部署接口不变。新增数值唯一入口为 `all_terrain.clutter_consistency` 与 `all_terrain.front_descent`；不修改正在运行的旧进程。新目标用 `--init-cts` 创建新 run，严格 `--resume` 继续沿用原 run 配置。

抗干扰项只在真实平地/平地墙课程、有至少三轮支撑、常规阶段、中央教师扫描平坦且前向有效数据足够的样本启用。对训练副本添加前方高块、侧墙、门框、窄柱四种成片高回波，保留中央支撑区、命令、本体历史、有效性和置信度；不填未知格，不改 PPO 行为观测。完整解码后的腿动作匹配未增强分支的停止梯度参考，教师和参考动作均经过软件限位接受门。轮速不作一致性约束。它是观测反事实增强，不是物理行人课程，不提供导航/避碰；真实上下阶、坑、块、平台不应用这一不变性。新增 `clutter_*` 诊断必须报告实际样本量，不能仅看 loss=0。

本轮不增加固定蹲伏高度/统一关节角，也不放宽关节限位、离地间隙或冲击约束。单策略继续通过真实地形学习姿态；自适应高度目标需先确定适用支撑面、关节可达性和腹部阶沿间隙。

## v21 直行航向与平台运动质量

数值唯一入口为 `all_terrain.motion_quality`。仅直行和平台启用；v20 楼梯暂停原位保持继续保留。观测、动作、网络和部署航向反馈不变。采用新目标需 `--init-cts` 创建新 run，不能用旧 run 的严格 `--resume` 注入新目标。

日志 `CTSAllTerrain/motion_quality/` 分 teacher/student 与 straight/platform 记录航向、过渡和停车样本；`failure_heading` 与 `failure_hold_quality` 区分新硬门，不把旧 yaw RMS 改成另一种单位。账本随 checkpoint 保存重载，计数只在初始化分配，不随物理步清零。

## v22 零速学习与停稳计时

固定 `model_0 / model_2000` 回放发现：楼梯暂停仍明显后退；平台存在探索噪声打断连续停车、idle 历史跟踪评分与末端目标冲突，以及 float32 连续计时误差。v22 的数值以 `configs/distillation/cts.json` 为唯一台账：

- `algorithm.stop_exploration_scale` 仅在可部署的原始三轴命令全零时缩小 Gaussian std，教师/学生一致；采样、rollout、PPO log probability 与 KL 同一分布，教师参考 anchor 归一化维持原值。缺省字段保留旧探索强度；部署的确定性均值与观测维度不变。训练新增停车/运动 KL 与提前停止统计，观察较窄分布是否压缩 PPO 更新。
- `all_terrain.stair_stop.retreat_weight` 对暂停零速阶段的机体世界 X 倒退速度和全轮平均位置差分倒退速度取较大者处罚。覆盖无接触滑移的纯滚退，在耗尽位置容差前产生反馈；进入暂停的前进帧不计，恢复后释放。保留原位位置、前后支撑、滑移、姿态和连续停稳验收条件，不奖励单纯增加关节力。
- `all_terrain.motion_quality.idle_terminal_hold` 让平台 idle 的两轴成功门采用固定位置/朝向/速度/前后支撑的 `hold_ok`，历史 linear/yaw RMS 仍作诊断但不再伪报为失败原因。平台前进的空间到达条件、高台安全足迹门不变。
- 成功持续时间、楼梯停稳恢复/暂停超时、平台落地确认均使用整数完成帧计数，日志秒数由计数派生；同时统一阶段边界的浮点精度。非整帧时间向上取整，不把不足时长判为完成。这项数值纠错也适用于旧配置。

## v25：双侧墙零命令原位停驻

配置入口为 `all_terrain.wall_hold_practice`。用户观察到双侧墙附近零命令仍后退，楼梯会放大这种后退；v25先在真实平地走廊中隔离训练零命令停驻。墙体几何复用 `wall_practice` 的 corridor，保留原支撑面可见性和传感器延迟，不向策略添加墙标签，不加制动器、不夹动作、不改变PD。

在教师和学生各自的 motion 环境中固定保留专项配额，剩余环境继续原通行与运动命令；上楼、楼梯停驻和暂停恢复保持原任务。配额按环境而非重置概率，避免专项短回合被长通行回合稀释。墙宽和扰动沿独立学生晋级账本推进，随机出生纵向位置、侧向偏置和可行朝向。具体比例、阈值、持续时间和权重只以 `cts.json` 为准。

全程外部命令为零，允许既有内部航向反馈。出生时固定机身和四个轮心的位置/航向锚点，宽限期间也不重定锚。越出位置/航向容差后本回合不得成功，返回原位或换位置再停不清除记录。成功要求机身及每个轮心速度、接触滑移和实测角速度合格，至少三轮且前后均有支撑，连续保持规定时长，无物理失败。位置容差是仿真可测的工程停稳定义，不是宣称数学上的绝对零运动。

`CTSAllTerrain/wall_hold/{teacher,student}/` 独立记录成功、超时、位置逃逸、最大后退/漂移、机身速度、轮心速度、接触滑移、角速度失败，以及各项奖励成本；原 wall_corridor/上楼/暂停成功率不混入专项。旧检查点通过 `--init-cts` 迁移权重到新v25 run，优化器和课程重新建立；旧v24不能直接 `--resume` 升级。

本次实现与验证收据见 `logs/evaluation/cts_v25_wall_hold_20261101/`。训练由用户启动，命令见其中 `TRAIN_COMMAND.txt`；预检与零更新冒烟不代表新策略已学会。后续性能验收应同模型/同命令/同出生姿态对比开放平地和双侧墙，并检查原墙间通行和楼梯暂停恢复，避免零速专项以牺牲非零命令能力换分。


## v26：窄双墙与独立 C 接管

`all_terrain.wall_practice.corridor_width_m` 固定 corridor 实际宽度，从初始等级直接覆盖目标窄双墙，后续等级也不先退回宽墙。其他墙型保留各自几何。原墙边停驻配额拆为直接停驻和 C 接管两组，教师、学生分别计数，两组分别晋级；分配与时序唯一来源为 `all_terrain.wall_hold_practice.handover`。

C 课程模拟已经站立的 ready→C：等待期间真实运行默认站姿、零轮速和基准增益；满足前后有效支撑、姿态和有限值条件才接管。接管不重置物理位置，按当时实测机身与轮心固定锚点，清空传感器历史、动作延迟与航向反馈，按部署接管时序渐入策略。关节限位检查在等待控制器恢复最终目标之后执行。此课程不模拟从趴伏到 Z 的完整起立过程。

等待帧不进入 PPO、学生蒸馏和时序辅助损失，也不计停驻成功时长。接管后的位移越界立即锁定失败，动作渐入宽限不能掩盖后退。日志 `CTSAllTerrain/wall_hold/c_handover/{teacher,student}/` 与直接停驻分开，包含接管次数和接管前超时；不能用等待阶段的受控静止宣称策略学会停车。

新目标使用 `--init-cts` 从退化前 v24/2500 新建 run，不继续 v25 优化器/课程状态。使用 `logs/evaluation/cts_v26_narrow_handover_20261101/TRAIN_COMMAND.txt` 中命令；训练由用户启动。原有楼梯任务保留，此次没有扩大楼梯难度。下一阶段先验收窄墙直接停驻和 ready→C 两组教师/学生的严格成功、漂移和接管抖动，再决定楼梯扩展。零更新验证只证明接线、几何、存储和执行契约，不证明停驻能力已经学会。
