# Ubuntu 长按不连发与 MuJoCo 按住命令失效

## 现象与真因

- 长按左方向键只移动一次，长按 W 不能持续控制 MuJoCo。
- 真实桌面为 GNOME / X11。GNOME 的 repeat 设置为 true，X11 全局连发也是 on，但 `xset q` 的四行 `auto repeating keys` 位图全为零；因此普通按键均不连发。尚未确定哪个程序清空了位图，不能据此归咎于任何远程桌面程序。
- MuJoCo 3.10 的 passive viewer 按键回调在本机实测只提供首次 PRESS。原 `TeleopKeyboard` 依赖后续重复事件刷新时间戳，持续按住也会超时停下。这是独立于系统连发设置的另一处问题。

## 修法与调用位置

- 恢复当前 X11 会话中已映射普通按键的连发位；保留修饰键、按键映射、连发延迟及速率。仅 `xset r on` 无法修复逐键位图全零。
- `deploy/deploy_mujoco/keyboard_input.py` 通过 X11 的 `XQueryKeymap` 查询移动键实际状态；用 MuJoCo 窗口回调记录焦点窗口，焦点不匹配则返回空集合。
- `deploy/deploy_mujoco/deploy_mujoco.py` 的 `TeleopKeyboard.on_keycode()` 记录窗口事件，`velocity_command()` 合并窗口按住状态和终端短时输入；退出时关闭 X11 连接。
- 当前 X11 仿真窗口按住持续运动、松开立即停、失焦立即停。非 X11 会话保留终端连发及超时方式；没有新增 Python 包。重新启动部署程序后加载新实现。

## 判据与执行结果

以下均为本次真实桌面测试；合成输入只用一次 key-down 和一次 key-up，不人工生成重复事件。
