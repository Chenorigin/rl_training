# Baseline 214700 与 Quiet V1 230300：all_terrain 实测

## 本次结果

楼梯段平均法向触地速度下降35.4%，平均法向比动能下降52.7%，平均40ms力峰下降32.9%；单位实际XY路程的累计法向比动能下降39.1%。改善主要在上楼：平均法向速度1.829→0.894m/s。下楼改善较小：0.603→0.535m/s。

新触地数110→145；最大单次力峰1681.8→1753.3N，反而增加4.3%。上坡平均法向比动能0.0069→0.0295J/kg、平均力峰69.6→80.2N，也有退化；不能概括成所有地形或所有撞击均改善。楼顶平台baseline只有5次事件，样本很少。

## 运行与口径

- 同一 M20 MJCF、all_terrain.xml、出生点 x=-1/y=0/yaw=0、前进指令 0.5 m/s；50Hz 策略、200Hz 物理，最多120秒，首次跌倒即停止。
- checkpoint/模型/地形/采样代码 SHA256 及判据在只读 evaluation_contract.json；本次两份运行均已完成。
- 法向触地速度 v=max(0,-v_pre·n)，n 来自高程图拟合；轮体中心碰撞前速度，不包含轮胎旋转接触点速度。
- 法向比动能 e=v²/2（J/kg）；轮体质量乘以 e 仅是轮体动能代理，不是整条腿有效碰撞动能。另有碰撞前轮心总平动速度/动能，保存于 CSV/JSON。
- 力：轮足与静态地形接触合力模长，逐次事件取开始后8个5ms物理步（40ms）的峰值；也保留首步力。
- 初始100ms不计；失败运行剔除末20ms及不完整力窗口；位置按机身x归段，两者共同完整路段截至 x=11。滑滚持续支撑不重复算新触地。

## 任务覆盖

- baseline：运行 31.34s，最大机身x=12.409m，跌倒=True，终点线越过=False，末帧所有轮心均在赛道内=False，原入口 cleared_terrain=False。
- quiet_v1：运行 120.00s，最大机身x=53.481m，跌倒=False，终点线越过=True，末帧所有轮心均在赛道内=False，原入口 cleared_terrain=False。

Baseline在坡顶附近偏出路线后触发跌倒；V1在约84秒越过x=38且120秒未跌倒，但末帧轮心越界，不能称为严格全地形成功通过；也未逐障碍验证绕行。后半程只有V1数据，不作跨模型比较。两者楼梯段均完整覆盖，但轨迹和触地次数不同。

## 限制与产物

- 每模型一次确定性固定指令试验，未进行多种初态/多指令统计；不是显著性结论，也不是实测声音或分贝结论。
- 法向是高程图估计；台阶边缘拟合可能退化，JSON包含每段 normal_fit_valid_fraction。台阶归段以机身位置，前后轮跨界时不是精确轮下地形标签。
- 楼梯末端接触更少/更多会改变按事件均值，因此同时给事件数和单位路程累计比动能。
- comparison.json 包含各段/各轮/整域均值、中位数、P95、最大值，以及碰撞前总轮心速度和轮质量动能。
- *_touchdowns.csv 是逐事件原始分析表；*_quiet.npz 是200Hz原始信号；*.log 是运行日志；comparison.png/pdf 是比较图。
- MuJoCo 无声、无GUI批量执行，未观看实时窗口；物理与原部署入口相同，图由真实采样生成。
