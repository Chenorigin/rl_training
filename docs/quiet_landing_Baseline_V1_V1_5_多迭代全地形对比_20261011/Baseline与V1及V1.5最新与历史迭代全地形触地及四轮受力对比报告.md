# Baseline、V1、V1.5多迭代MuJoCo all_terrain对比

Frozen latest V1 255900 and V1.5 233500, historical V1 230300/237200, matched iteration V1/V1.5 230300 and233500, Baseline214700. Three previous verified matching-source rollouts reused; four new actual rollouts.

## 本次结论

- 七个固定checkpoint均无跌倒且完整通过。最新不代表最优：V1的255900下楼相比237200速度均值+31.4%、比动能均值+62.1%、力峰均值+29.1%；相对baseline下楼这三项也分别+4.5%、+5.5%、+13.8%。
- V1.5最新233500相对baseline，上楼速度/比动能/力峰均值分别降低46.2%/62.2%/38.3%，下楼分别降低19.1%/30.6%/17.7%；下楼最大力峰降低33.0%。
- V1.5最新233500相对自身230300，全地形每米累计比动能增加26.7%，耗时82.60→89.14秒；下楼最大力峰仍改善4.9%，但平均力峰增加7.3%。
- 同233500迭代，V1.5比V1下楼平均力峰降低12.3%、P95降低28.6%、最大力峰降低25.3%；全地形每米累计比动能反而增加8.5%，耗时增加7.5%。
- 本次全地形每米累计比动能最低为V1.5的230300（2.746J/kg/m）。它可保留为后续复测候选，不根据单回合宣称最终最优。
- 四轮平均受力均衡未见一致改善：全地形平均力对角差占比，Baseline为7.14%，V1_230300为2.72%，V1_255900为8.32%，V1.5_230300为16.35%，V1.5_233500为12.99%。须进一步复现稳定支撑门控，不能据此直接认定均衡奖励有效或无效。

## 口径与限制

- 每个模型一次确定性真实物理闭环；3份历史回放经checkpoint与源码哈希核验后复用，4份新回放本轮执行。失败回合整体排除触地汇总，保留状态与轨迹。
- 使用同一外部路线反馈：世界前进0.5m/s、横向居中和朝向纠偏；反馈随姿态变化，各模型实际命令序列不会完全相同。
- 触地速度为碰撞求解前轮心沿高程图估计法向的接近速度；比动能=v²/2，轮体动能=轮体质量×比动能（详见CSV），不等于整机有效碰撞能量。NPZ旧energy_definition字段描述的是另一个平移动能量，本文实际按speed数组重算并核验specific_energy。
- 力取静态地形实际接触合力模长，新触地起8个5ms求解步内峰值；使用5/2N滞回、至少10ms离地及100ms初始化保护、踏面法向力比例至少0.5；末尾不完整40ms窗口排除。
- 路段按机身x切分；前后轮可能跨段，完成终点不能单独证明每个障碍都没有绕行。
- 最新V1与V1.5训练时长不同；同230300、233500对照控制累计更新次数，但单条训练和单回合仍不能证明奖励变化的统计因果。两训练都从baseline214700继续，seed42、固定学习率1e-5、4096环境。
- 四轮受力平均包含摆动零力；全程平均或平地平均不等于训练的稳定四足支撑门控。MuJoCo采样器未复现V1.5稳定门控，本报告不使用其stable_has_samples=0判定学习失败，也不把采样器的默认V1奖励值当作V1.5奖励。
- 未测真实声音、声压或分贝；未进行真机和多种速度、多次随机回合鲁棒性测试。
