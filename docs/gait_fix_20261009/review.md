## P2 / 有限性

### P2-A：方向惩罚放大后须防止新的任务退缩

原方向总成本上界2；现在每个分量软界4，三分量总成本上界12，权重−2意味着极端理论−24/s。1m 横向偏移的原分量约0.93，现在约1.62，速度和偏航 mix 同时从0.5升至1。修法针对梯度饱和合理，但不能把极端界或 CPU 正确当作训练表现正确。

具体建议：训练前量化 baseline 固定路径轨迹上新/旧方向成本与速度、task crossing、总 return 的比例；TensorBoard分开监控激活率、偏移/偏航与停滞/后退，早期能力下降立即回看奖励账。不要只用 `Episode_Reward` 总奖励上涨作为验收。

### P2-B：后腿 shaping 是有限准备引导，不是每次引导都保证交替

新 score 对每个目标付新增最大值，最大总支付每目标不超过1，无法原地循环无限刷奖。资格从不满足变为满足时可能给出一次 credit，即便变化主要来自其他腿加载；同阶序列也可能得到有限准备分。因此它补足学习信号，最终是否实现交替仍应看 `transition_per_landing`、same-tread/skip 与严格跑长，不能以 lift credit 增大宣称成功。

如闭环中出现“仅换重心赚准备分”，再改为目标激活时记录两腿原始几何score、而非资格乘0后的score，限制资格切换造成的虚假增益。当前没有发现无限刷奖或重启刷奖反例，故不建议凭假设再叠加奖励。

### P2-C：姿态阈值需要闭环验收

阈值使用身体/重力 whole-leg hip→wheel 角，未改变原角定义。支撑b25/g20、摆动b45/g35较之前更严格，但不能仅据阈值保证视觉姿态；还有台阶高度放宽、机体俯仰、足端落点。应以固定下楼轨迹的承重/摆动各自正角P95与峰值验证，并看下楼通过率。
