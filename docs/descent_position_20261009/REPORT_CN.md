## 新结论（现象 / 真因 / 判据 / 修法）

现象：入口位置奖励成本降低，左后腿略后收，但右后腿最大前伸不变、实际碰撞加深。

真因：奖励接线遗漏和腾空时完全不罚已被生产路径执行排除；本轮究竟受优化保护、信用分配、摆腿时序或其他动作耦合限制仍未判定，不编造唯一根因。

判据：奖励下降、前伸均值降低、接触记录下降都不能替代精确碰撞间隙。固定物理闭环仍有负间隙即失败；同时必须走完、无摔、无越界。

修法：保留有据可回退的实验改动与失败产物，不替换原模型。后续若继续位置奖励路线，应做单变量的优化强度/信用分配诊断；若转几何/时序路线，应独立验证完整入口轨迹，不与本轮同时改动以免无法归因。这两条均尚未实施。
